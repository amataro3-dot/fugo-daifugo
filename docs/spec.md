## 0. このゲームについて

- ゲーム名: 富豪大富豪(ポーカー × 大富豪のオークション制コイン戦)
- 身内で遊ぶ用。スマホ(縦画面)のみ対応。
- 公開: https://amataro3-dot.github.io/fugo-daifugo/

## 1. 技術方針

- ホスト方式: 部屋を作った人のブラウザが、シャッフル・配札・ルール判定・コイン計算・コンピューターの思考を行い、結果を Firebase に書く。他の人は表示と操作の送信だけ。
- ホストもプレイヤーとして遊べる。ホストはゲーム中、画面を開いたままにする。
- ホストが切れたら、接続中の人間(コンピューターと退出した人を除く)で、先に入室した人がホストを引き継ぐ。そのため、ゲームの状態はすべて Firebase に置く。
- データベース: Firebase Realtime Database(無料の Spark プラン)、プロジェクト fugo-daifugo。認証は匿名認証(名前を入力するだけ)。
- 公開: GitHub Pages。技術は HTML + JavaScript のみ(ビルド不要)。
- 手札は Firebase 上に全員分を置き、画面側で自分以外を伏せる(開発者ツールで見えても気にしない)。
- チャットなし。
- コンピューターの手番は、ホストが約1.5秒待ってから出す(入札などの伏せる操作は約0.8秒)。
- 将来、ホスト切断で止まるのが問題になったら、サーバー方式(Cloudflare Workers、Supabase など)を提案する約束。

## 2. 部屋と参加者

- 入室時に名前を入力。「ルーム作成」か「ルーム入室」を選ぶ。ルームIDは数字4桁(使用中の番号を避けてランダム)。
- 対戦者と観戦者を合わせて最大8人。対戦も最大8人。
- ホストがすべて設定する。
- ゲーム開始後に入った人は、最後まで観戦のみ。
- 観戦者は、全員の手札が見える(途中から入っても)。

ホストの設定項目
- 初期コイン: 20〜40枚
- ラウンド数: 5〜12
- 親決めの入札上限 X: 5〜10枚
- 対戦人数: 2〜8人。足りない分は強め固定のコンピューターで補充(強さは選べない)
- 借金ルール: あり / なし

## 3. ラウンドの流れ

**席決め → 配札 → カードマーケット → カードチェンジ → 親決め(ブラインドオークション) → 対戦 → 精算**

- ラウンド開始時に、コインが残っている人だけが参加する。前ラウンドの退場者は、席決めの前に観戦者になる。
- このあと、各フェーズで「親」と書いたら、**前ラウンドの勝者**のこと(マーケットとチェンジの順番の起点)。
  前ラウンドの勝者がいないとき(1ラウンド目、ノーゲームのあと)はランダムで決め、
  「ランダム(スタート時は勝者がいないためランダムで決めます)」のように表示する。
  対戦で最初にカードを出す人(親決めオークションで決まる)とは別。

### フェーズ1: 席決めオークション
- 1ラウンド目: 全員ランダムで着席(オークションなし)。対戦が2人だけのときも、オークションなし。
- 2ラウンド目以降(3人以上):
  - 前ラウンドの勝者が、先にランダムな席に座る(入札しない)。
  - 残りの人は、**1〜5枚を伏せて入札するか、パス**(0枚の選択肢はない)。コイン0枚の人は自動でパス(神の手を借りられる人は入札できる)。
  - 全員そろったら約3秒、一斉公開。入札したコインはポットへ。
  - 賭けた枚数が多い人から順に、好きな席を選ぶ。
  - **5枚を賭けた人が1人だけ**なら、その人だけが選び、他の人は全員ランダム。
  - **同じ枚数の人がいたら(2位以下でも)、その人たちで競り合い**。1枚ずつ「上乗せ / 降りる」。青天井で、1人残るまで。
    - 聞く順番: **前ラウンドの座り順で、前ラウンドの親(最初にカードを出した人)の次の人から**。
    - 3人以上の同点: 最後に残った人が先、そのあとは**後から降りた人ほど先**(先に降りた人が一番後)。
    - 競り合いの上乗せもポットへ。コインが足りない人は自動で降りる(神の手を借りられる人は除く)。
  - 席の選び方: テーブルのまわりの「空席」をタップして座る(確認1回)。自分は座るまで「未着席」。座ったら自分が画面の下に来る。
  - パスした人は、余った席にランダムで座る。
  - 席決めで使ったコインはポットへ(親決めとは別)。

### フェーズ2: 配札
- 全員に3枚ずつ配る。

### フェーズ3: カードマーケット
- 山札から3枚を**表向き**で場に出す(①②③)。
- **親から時計回り**に、全員が「どれか1枚を選んで1〜5枚ベット」か「パス」を**伏せて**選ぶ。
- 全員そろったら約3秒、一斉公開。**ベットしたコインは、この時点でポットへ。競り負けても戻らない。**
- 各カードで一番多く賭けた人が、そのカードを手に入れる。1人だけが賭けたカードは、その人のもの。
- 同じカードに同じ枚数の人がいたら、競り合い(1枚ずつ「上乗せ / 降りる」、上乗せもポットへ)。
  - 順番: **親が入っている同点を最優先**、残りはカードの順(①→②→③)。
  - 各競り合いの中は、親から(親がいなければ、親から時計回りで近い人から)。
  - 同点の全員がコイン不足(神の手も使えない)なら抽選。
- 手に入れた人は、**自分の手札から捨てる1枚をタップして交換**(手札は3枚のまま。交換は必ずする)。捨てた札は捨て札。
- 流れ: ベット(1周目) → 同点の競り合い → カードの受け取り(交換) → **誰も賭けなかったカードがあれば、親からもう1周**(1周目で手に入れた人も参加できる)。
- 2周目でも誰も賭けなかったカードは捨て札(山には戻さない)。
- 神の手(借金)は使える。

### フェーズ4: 倍々カードチェンジ
- 親から席順で回す。パスした人は飛ばす。
- 1回のチェンジは「手札から1枚を選んで、山札から1枚引く」。捨てた札は捨て札。
- 1人1回ずつ、最大3周(最大3枚)。コストは1枚目1コイン、2枚目2コイン、3枚目4コイン(合計7)。使ったコインはポットへ。
- 自分の番で「パス」を選ぶと、その人のチェンジは終了。
- 3周回しきるか、全員がパス・終了したら次へ。
- 警告: 手札が上がり禁止カードしかない状態でチェンジできるのにパスしようとしたら、「このままだと反則負けになりますが、本当にチェンジしなくていいですか?」と確認。
- コイン不足: 手持ちで払えない回は、神の手を借りられる人(手持ち1枚以上)だけが借金してチェンジできる。それ以外は自動で飛ばす。ちょうど0枚になる回は、借金にならないので普通に払う。

### フェーズ5: 親決め(ブラインドオークション)
- 入札できる人: コインを1枚以上持っている人、または神の手を借りられる人。
  (このゲームで神の手を使用済みで、コインもない人はパス扱い)
- **1〜X枚を伏せて入札**。手持ちより多い枚数も選べ、そのときは「神の手を借りますか?」と聞く。
  「いいえ」なら枚数が手持ちの枚数に戻って選び直し。コイン0枚の人は「パス(神の手を借りない)」も選べる。
- 全員そろったら約3秒、一斉公開。出したコインは全額ポットへ(足りない分は借金)。
- 単独の最高額の人が親(最初にカードを出す人)。誰も入札しなければ、マーケットの親が最初に出す。
- 最高額が同点なら、同点の人同士で競り上げ(1枚刻み、青天井、1人残るまで)。追加分もポットへ。聞く順番は席順。
  - コインが足りない人は自動で降りる。ただし神の手を借りられる人と、すでに借金している人は降りない。
- 神の手を使えるのは、**同点で競り合っている人だけ**(と、ブラインドの入札そのもの)。
  一度借りた人は、その競りでは相手が降りるか相手も借りるまで、何枚でも上げられる。
- 強制終了(全員が神の手を借りた):
  - 競り上げ中に、残っている全員が借金した → **最後に借りた人**が親。
  - ブラインドの時点で、同点の全員が借金していた →
    1. 借りた枚数が一番少ない人
    2. それも同じなら、前ラウンドの勝者(マーケットの親)
    3. その中に勝者がいなければ、勝者から時計回りで一番近い人
  - 表示: 「全員が神の手を借りてしまったため、最後に神に助けを求めた人からゲーム始めさせてもらいます。」

### フェーズ6: 対戦
- 親から、席順で時計回りにカードを出す。パスした人は、その場が流れるまでパス状態で、飛ばして回す。
- 最初に手札をなくした人がラウンドの勝者。そのラウンドはそこで終了。他の人の残りカードは関係ない。
- 全員が反則負けで勝者がいないときは、ノーゲーム。ポットは次ラウンドに持ち越し。ラウンド数は1つ消費する。

### 精算
- 勝者がポットのコインをすべて受け取る。借金があれば先に返す。
- 持ち越しのポットは、次ラウンドのポットに足される。
- リザルト画面: 勝者、ポットの獲得額、借金の返済、各プレイヤーのコインを**コインの多い順**に(同数は同順位)、退場する人。
  上がりの全画面表示(タップで閉じる)のあとに出る。全員が「OK」を押したら次ラウンドへ(コンピューター・観戦者・切断中の人は待たない)。

## 4. 対戦ルール(大富豪部分)

### カードの強さ・出し方
- 強さ: 3 < 4 < … < K < A < 2 < ジョーカー(ジョーカーは単体出しのとき最強)。
- 出し方は、1枚出し・ペア・3枚出し(階段なし)。場と同じ枚数のみ。同じ強さは出せない。
- ジョーカーは、ペアや3枚出しの中で任意の数字の代わりに使える。マークは出した人が指定し、場のジョーカーに「(♠)」のように小さく表示する。
- 3枚出しは手札が3枚なので、そのまま上がり。

### パスと場流し
- 全員がパスしたら場が流れ、最後にカードを出した人から再開(その人が脱落していたら、席順で次の人)。
- 出せるカードがない人を自動でパスにすることはしない。出せなくても自分でパスを押す。
- 全員パスで流れたら「全員パスで場が流れます / 〇〇さんから」を表示。

### 8切り
- 8を含む出し方(8+ジョーカーのペア含む)で場が流れ、出した人から再開。
- 出したカードを約1.5秒見せて「8切り!」と表示してから流す(その間は手番が止まる)。

### 11バック
- Jを出した人が「11バックしますか?(バックする / しない)」を選ぶ。「バックする」なら強弱が逆転(3が最強、2が最弱)。場が流れるまで続く。8切りで流れたら通常に戻る。
  - すでに逆転中のときや、Jで上がるとき(最後の札)は聞かない。CPUは残りの手札に弱い数字が多ければバックする。
- 解除の概念はない(逆転中にもう一度Jが出ても逆転のまま)。

### スペ3返し
- ジョーカー単体に、♠3で返せる。返したら、出した♠3を約1.5秒見せて「スペ3返し!」と表示し、場が流れて♠3の人から再開。
- 返せる条件: しばりなし → 返せる / ♠のしばり中(激しばり含む)→ 返せる / ♠以外のしばり → 返せない。
- ジョーカー単体のあとも全員に手番が回る(♠3以外は出せない。♠以外でしばられていれば♠3も出せず、全員パスで流れる)。
- ジョーカー単体ではしばりにも激しばりにもならない。激しばり中にジョーカー単体が出ても、場のしばりはそのまま残る(新しく激しばりになったわけではない)。
- 表示: しばりなしの場は「ジョーカー(♠3のみ)」、♠のしばり中は「激しばり ♠(♠3のみ)」など、♠以外のしばり中は「しばり ♥(返せません)」。

### しばり(出した人が選ぶ)
- しばりを作れるのは、**前の人が出した札と同じマークを出したときだけ**。親の1枚目はしばれない。
- 1枚出し: 前と同じマークなら「しばる / しばらない」(激しばりができるときは「激しばり」も)。
- ペア出し: 「片しば / 両しば / しばらない」。
  - 片しば: 前の札と同じマークのうちから**1つを選んで**しばる(1つしかなければ自動)。場には「片しば ♥」。次の人はそのマークを含めばOK。
  - 両しば: 前と同じ2つのマークで出す。場には「両しばり ♥♦」。
  - 片しばの場で、しばりのマークを含むペアが出て、もう片方のマークも前の札と同じなら「もう片方もしばりますか?」→「しばる」で両しばりになる。
- しばり中でもジョーカーは出せる。

### 激しばり(出した人が選ぶ)
- 同じマークで次の数字(♠5の次に♠6)を出した人が発動できる。しばり中でも、しばられていない場でも。
- 発動後は、同じマークの次の数字のみ出せる(11バック中は逆向き: ♠5の次は♠4)。
- ペアでも有効だが、両しばのときだけ。ペアの中のジョーカーも使える(マークは出した人が指定)。
- 順番は 3→4→…→K→A→2→ジョーカー。♠7の次は♠8で、8切りで流れる。
- 激しばり中でもジョーカー単体は出せる。出たあとは♠3返しだけが可能。誰も返さなければ流れて、ジョーカーを出した人から。
- 未確認: ♠2を出した後(次がジョーカー)の扱い。

### 表示(場)
- しばり・11バックは、場の上に色付きの帯で表示(激しばりはオレンジ、しばりは黄色、11バックは水色)。
- 場のカードは手札と同じ大きさ。

## 5. 禁止上がりと反則負け

- 次のカードを含んで上がると反則負け: 2、8、ジョーカー。11バック中は3も。全部3の3枚出しは、通常時はOK、11バック中はNG。
- 例外: ジョーカー単体のあとに♠3で返して上がるのはOK(11バック中でもOK)。
- 反則負けの人は、すべてのカードを捨てて脱落。投入済みコインはポットに残り、残りの人で続行。
- 警告1: 手札が上がり禁止カードしかないとき「上がり禁止カードしかありません」。
- 警告2: 禁止上がりになる出し方をしようとしたとき「反則負けになりますがよろしいですか?」。
- 反則負けが出たら、出したカードを全画面で見せ、**全員(コンピューター・観戦者・切断中の人を除く)がタップするまで**手番は進まない。

## 6. 借金ルール「富豪の神の手」(ホストが あり/なし を選ぶ)

基本
- **1人がゲーム全体で1回だけ**使える。
- 手持ちで足りない分だけ借りる(例: 手持ち3枚で8枚出すと、借金5枚・手持ち-5枚)。
- 借りる前に「次のターンからマイナスになります。富豪の神の手を借りますか?」と確認。
  「いいえ」なら、枚数が手持ちの枚数に戻る(席決め・マーケット・親決め)/ チェンジはパス扱い。
- 借りたあとはコインがマイナスなので、そのラウンドのあとのオークション・チェンジは自動でパス(対戦には普通に参加)。
- 借金中の人は、名前の前に**丸で囲んだ「貧」**を付け、コインはマイナスで表示する。
- コンピューターも借りる(親になれば3枚出しで即上がりできるとき、上がり禁止カードしかなくてチェンジが必要なときだけ)。

使える場面
- 席決め: 1〜5枚の入札(手持ちが少なくても5枚まで選べる)、同点の競り合い。
- マーケット: 1〜5枚のベット、同点の競り合い。
- チェンジ: 手持ち1枚以上で、その回のコストが払えないとき。
- 親決め: ブラインドの入札、同点の競り上げ(5章フェーズ5)。

強制終了(競りの相手が全員借金済みで、最後の人も借りた)
- 席決め・マーケット: 最後に借りた人の勝ち。席決めは「全員が神の手を借りてしまいましたので、最後に神に助けを求めた人から決めてください。」
- 親決め: フェーズ5のとおり。

返済とペナルティ
- 借金した人が勝ったら、ポットから先に借金を返す。残りが所持コイン。返しきれなければ、勝者でも退場。
- 借金した人が負けたら、マイナスのまま次ラウンドの前に退場(順位は「借金して負けた人」)。
- 最終順位は「所持コイン − 借金した合計額」で比べる(返済しても記録に残る)。マイナス同士は、マイナスが小さい方が上。

## 7. コインの原則

- オールイン禁止は廃止。所持コインは全部賭けてよい。ポーカーのオールインの配当ルールは使わない。
- コイン0枚の人は、そのフェーズのオークションをパスして、ゲームには普通に参加する(神の手を借りられる人は、借りて参加できる)。
- ポットの持ち越し: 勝者がいないとき(ノーゲーム)、リタイヤした人の手持ちコインは、次ラウンドのポットへ。

## 8. 切断・退出・リタイヤ

- 接続中は手番の時間制限なし。
- **切断**: 誰かの接続が切れたら、**ゲーム全体を止めて**全員で待つ。全員の画面に「〇〇さん接続が切れました。復帰中です。(残り m:ss)」を表示。時間はサーバーの時刻で数える。
- 3分以内に戻れば、そのまま再開。同じスマホの同じブラウザなら、自動で元の席に戻る(別の端末・別のブラウザからは戻れない)。
- **3分を過ぎたら、または自分で「ロビーに戻る」(退出)を押したら、すぐリタイヤ**:
  - 手札は捨て、そのラウンドから脱落(入札・席決め・マーケットの途中なら自動でパス)。
  - 投入済みのコインはポットに残る。手持ちのコインは次ラウンドのポットへ(アナウンスする)。
  - 順位は最下位。以後は観戦者。まわりの欄に「リタイヤ」と表示。リタイヤした人が戻ってきたら観戦者として入る。
- リタイヤなどで対戦者が**1人だけ**になったら、その人がラウンドの勝者になってポットを受け取り、ゲーム終了(その人が優勝)。
- ホストが切断・退出したら、次の人がホストを引き継いで続行(3分の見張りも引き継ぐ)。
- 部屋の後始末: 全員が退出した部屋のデータは消す。ゲーム中に退出した人の記録は、最終順位のあとロビーに戻るときに消す。

## 9. 退場と勝利判定

- ラウンド終了(精算)後に、コインが0枚以下の人は、次ラウンドの席決めの前に退場して観戦者になる。
- 勝者はポットを受け取ってから判定する(0枚でラウンドを終えても、勝てば退場しない)。
- 残りが1人になったら、ラウンドが残っていてもそこで終了し、その人が優勝。
- 設定したラウンド数が終わったら、「所持コイン − 借金した合計」が最も多い人が優勝。同数は同率。
- 退場者の順位(下から): 1. 反則負け・切断リタイヤ・退出 2. 借金して負けた人 3. コインを賭けて0枚になって負けた人。
  同じ理由なら、後で退場した人ほど上位。同じラウンドで同じ理由なら同順位。

## 10. 画面の仕様

画面は5つ
1. 入口画面: 名前、「ルーム作成」、「ルーム入室」(4桁)を1画面に。
2. ロビー: 入室者と設定を表示。全員が「準備完了」を押したら、ホストが「ゲームスタート」。
   入室者が人数より多いときはホストが観戦者を選ぶ(**未実装**。今は後から入った人が自動で観戦)。
3. ゲーム画面(下記)
4. リザルト画面(3章「精算」)
5. 最終順位画面: 順位、所持コイン、借金分の引き算、退場したラウンドと理由(借金・リタイヤ)。ボタンは「ロビーに戻る」だけで、押すと部屋全体がロビーに戻る。

ゲーム画面(スマホ縦)
- 自分を下に固定。他の人を上・左右に並べる(手番が時計回りに見える並び)。最大8人。
- 1人ごとの表示: 名前、コイン、手札の枚数(裏向きのカード)。パス・反則負け・リタイヤ・切断中の印。各フェーズの状態(入札済み、ベット済み など)。
- 観戦者には全員の手札を表向きで表示。
- トランプ風のカードは画像を使わず HTML/CSS で描く。
- 常に表示: ラウンド数(例: 3 / 8)、ポット、山札の残り枚数、場のカード、しばり・11バックの帯、手番の人の強調。
- 画面の隅に小さな「ロビーに戻る」ボタン(=退出。確認1回。対戦中ならリタイヤになる旨を表示)。
- 上がったとき、最後に出したカードを場に残す。
- **フェーズ最初の説明は全画面**(席決め・カードマーケット・カードチェンジ・親決め・対戦スタート)。「タップして開始」。
  **全員(CPU・観戦者・切断中・リタイヤの人を除く)がタップするまでゲームは進まない。** 観戦者はタップで閉じるだけ。
- **途中のログ**(交換しました、全員パスで流れます、一斉公開 など)は、**上の段のプレイヤーと場の間の欄**に出す。次のログが来るまで残す。文字が多いと場が少し下にずれる。
- **しばり・片しば・両しばり・激しばり・8切り・11バック・スペ3返し**は、画面の真ん中に約1秒大きく出して消す(タップ不要)。ログ欄にも残す。

カードの操作
- 自分の番に手札をタップして選び、「出す」で確定。ボタンは「出す」「パス」。
- しばれる出し方をしたら、「出す」のあとにポップアップで聞く(しばり、片しばのマーク、両しば、激しばり、ジョーカーのマーク)。
- カードチェンジ中は1枚だけ選べて、ボタンは「チェンジ(Nコイン)」「パス(チェンジ終了)」。
- 入札・ベットは「−/+」で枚数を選んで「入札する / ベットする」。マーケットは場のカードをタップして選ぶ。

## 11. Firebase のデータの置き方

```
rooms/(ルームID)/
  meta:     { host, started, created }
  settings: { coins, rounds, bidMax, players, debt("on"|"off") }
  players/(各人): { name, ready, joinedAt, spectator, online, offAt, coins, debt, debtTotal, seat, cpu,
                    exitRound, exitReason("zero"|"debt"|"retire"), retired, leaveReq }
  hands/(各人): [カード...]
  deck: [カード...]  lot: 数字
  actions/(キー): 操作の受付箱 { uid, type, cards, jsuits, lock, lockSuit, gek, back, n, c, borrow }
  game: {
    round, phase("seat"|"market"|"change"|"bid"|"play"|"result"|"final"), pot, order[], turn, rev,
    lead(マーケット・チェンジの親), prevWinner, parent(対戦の親), carryNext(次ラウンドへ回すコイン),
    seat{...}, market{...}, change{counts{}, done{}}, bid{...},
    field{cards, by, count, str, suits, jsuits}, lock{mode, suits, gek, pair}, passed{}, last, out{},
    foul{id, name, cards, acks}, clear{id, turn}, notice{text, id}(ログ欄), fx{text, id}(大きい演出),
    intro{id, kind, title, text, acks}(フェーズ最初の説明),
    winner, result{winner, gain, carry, repaid, last, outIds, acks}, ranking[]
  }
```
- 手札を別の場所に置くのは、将来サーバー方式にするとき手札だけ隠しやすくするため。
- 切断の検知: Firebase の onDisconnect で `online: false` と `offAt`(サーバー時刻)を自動で書く。
- カード表記: "S3"=♠3 / "H12"=♥Q / "JK1","JK2"=ジョーカー(A=1)。

## 12. 山札(ロット)

- 54枚(52枚+ジョーカー2枚)を1ロットとして、ラウンドをまたいで使い続ける。
- 尽きたら、その場で(配札・マーケット・チェンジの途中でも)新しい54枚をシャッフルして続行。「次のロットを使用します」とアナウンス。
- 使用済みのカード(出した札、捨てた札、マーケットの売れ残り、反則負けやリタイヤで捨てた札)は、ロットが尽きるまで戻さない。カウンティングも戦略の一部。
- ロットが変わると、同じカードが同時に2枚存在することがある。
- 山札の残り枚数を画面に常時表示。

## 13. 残っている確認事項

- ♠2を出した後(次がジョーカー)の激しばりの扱い。
- ペア・激しばりで、ジョーカーのマーク指定がかち合ったときの扱い。
- Firebase のセキュリティルール(身内用だが、最低限の書き込み制限)。
- 全員が切断したまま戻らない部屋の後始末。
